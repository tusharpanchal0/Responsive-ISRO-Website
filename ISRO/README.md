# ISRO-Inspired Responsive Website

A responsive, student-created front-end website inspired by India's space exploration journey. Built using **HTML5, CSS3 and vanilla JavaScript only**. No frameworks or build tools are required.

> **Important:** This is an educational portfolio project. It is not an official ISRO website and is not affiliated with or endorsed by ISRO.

## Features

- Responsive layouts for mobile, tablet and desktop screens
- Mobile navigation menu and accessible dropdown menus
- Search that finds matching content on the page
- Text-size accessibility controls
- Space-mission and educational-resource sections
- Existing project banner image and Chandrayaan lander video retained
- Semantic HTML, keyboard focus styles and reduced-motion support

## Run locally

1. Download or extract the project folder.
2. Open `index.html` in a modern browser.
3. For the best local development workflow, open the folder in VS Code and use the Live Server extension if installed. No `npm install` or build command is needed.

## Files

- `index.html` — page structure and content
- `style.css` — responsive styling and layout
- `script.js` — navigation, search and accessibility interactions
- `isro2.png` — original project banner image
- `Ch3_lander.webm` — original project video used in the hero section

## Upload to GitHub

1. Sign in to GitHub and create a new repository.
2. Keep the repository name simple, for example `isro-responsive-website`.
3. Upload the files and folders from this project (not the ZIP file itself).
4. Add a short repository description and keep `README.md` included.
5. To publish it with GitHub Pages, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
